GNF Theory

Understand the basic concept of Greibach Normal Form

What is GNF?

Greibach Normal Form is a special form of Context-Free Grammar where every production starts with a terminal symbol.

A → aα

Components

A is a non-terminal, a is a terminal and α represents zero or more non-terminals.

A → aBC

Main Idea

The important condition is that the first symbol on the right side must always be a terminal.

A → a

GNF Rules

Important rules that every GNF grammar should follow

Rule 1: Every production must start with a terminal.
Rule 2: The general form is A → aα.
Rule 3: A is a single non-terminal.
Rule 4: a is a terminal symbol.
Rule 5: α can contain zero or more non-terminals.
Rule 6: A production such as A → BC is not in GNF.
Rule 7: Epsilon production S → ε can be allowed as a special exception when the grammar permits it.

GNF Examples

Examples of valid and invalid Greibach Normal Form productions

✓ Valid GNF Example 

S -> aAB
A -> bB
B -> c

Why is it valid?

S → aAB starts with terminal a.
A → bB starts with terminal b.
B → c starts with terminal c.

Therefore, all productions follow the GNF rule A → aα.

✗ Invalid GNF Example 

S -> AB
A -> a
B -> b

Why is it invalid?

S → AB starts with the non-terminal A.

In GNF, the first symbol on the right side must be a terminal.

Therefore, S → AB is not a valid GNF production.

✓ More Valid Productions 

A -> a
A -> aB
A -> aBC
A -> bC
A -> cABC

All these productions begin with a terminal symbol such as a, b, or c.

✗ More Invalid Productions 

A -> BC
A -> Ba
A -> ABC
A -> ε

These productions are invalid because they either begin with a non-terminal or contain an epsilon production that is not being treated as the allowed start-symbol exception.
